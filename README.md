# Stepik Offline Downloader — видео и текст

Универсальный загрузчик Stepik с ручной передачей cookies.

## Подготовка

1. Скопируйте `config.example.json` в `config.json` и укажите `course_url` (ссылка на курс или на урок с `?unit=...`).
2. Скопируйте cookies из своего браузера в `cookies.txt` одной строкой значения HTTP-заголовка `Cookie`.
3. Запустите `go run .` (нужен Go 1.26.5+, как в исходном проекте).
4. Выберите `1` — скачать MP4, `2` — экспортировать текст в HTML и PDF.

Видео выгружается, как в предыдущем парсере, в папки разделов. Текстовый режим сохраняет `course.html`, локальные картинки в `assets/` и пытается создать `course.pdf` с помощью установленного Google Chrome, Chromium или Microsoft Edge. На macOS программа автоматически ищет браузер в `/Applications` и `~/Applications`, на Windows — в стандартных каталогах установки, на Linux — через `PATH`. Если браузер не найден, HTML останется доступен для открытия и ручной печати в PDF (`Ctrl+P`). При нестандартной установке можно указать `CHROME_PATH` с полным путём к исполняемому файлу.

### Ограничения

- Сохраняются только шаги с `block.name == "text"`. Задачи, комментарии, видео и другие типы шагов пропускаются.
- Встраиваемые iframe, аудио, формы и скрипты не экспортируются. Сложная математика (MathJax), внешние стили и некоторые нестандартные изображения могут потребовать доработки после проверки реального ответа `/api/steps/{id}`.
- При ошибке скачивания отдельного шага или картинки сообщение выводится в консоль, обработка продолжается. Проверьте счётчик ошибок: результат может быть неполным.
- Для PDF рекомендуется проверить первые страницы визуально; автоматическая проверка PDF на реальном платном курсе здесь не выполнялась.
- `cookies.txt` и `config.json` содержат приватные данные, не публикуйте их.
